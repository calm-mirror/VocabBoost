# VocabBoost · 词力引擎 2.2

一个给高中/大学英语学习者用的本地背词软件。它的原则只有一句：

> **学什么、学多少，由你自己决定；软件只负责组卷、记录、复习和打印。**

---

## 一、拿到软件后怎么用

### 1. 启动

发行版在：

```text
VocabBoost-2.2.0-win64\
```

双击里面的：

```text
VocabBoost-Launcher.exe
```

这个启动器会自动带 `--no-sandbox` 参数启动软件，并把数据放在发行版目录的 `VocabBoost-Data`。

如果启动器打不开，备选双击：

```text
启动 VocabBoost.cmd
```

**不要直接双击** `dist\win-unpacked\VocabBoost.exe`：在这台电脑上它需要 `--no-sandbox`，直接双击会没有反应。

> 当前不提供便携单文件：这台机器上便携外壳会报临时目录错误，压缩也会失败。请使用“启动器 + 文件夹版”。

### 2. 第一次打开：测试只是“推荐”

软件会引导你做一次 2 分钟的词汇量测试：

- 从高中 L2 开始，每级抽 5 个词；
- 认识 4 个（80%）才升级，否则回调一级；
- 最多 25 题；
- 测试中勾选“认识”的词，会标记为 L5 已掌握。

**重要：测试结果只是一个推荐等级，不会限制你学什么。**

- 你是高中生，但想考雅思？直接在首页勾 **L5 雅思/托福**，就能学雅思词。
- 你只想稳基础？只勾 L1–L2。
- 你完全不测、直接跳过？也可以，默认选中 L1–L2，你随时可改。

### 3. 输入今天想学多少

每天第一次点“开始今日学习”后，会先弹出：

> 今天想学多少个词？

- 快捷选 10 / 20 / 30 / 50；
- 也可以自己输入 1–100，例如 25、35；
- 学到一半退出，下次会按剩余数量继续；
- 同一天再学，按剩余数量继续；
- 今日目标完成后还想学，会问“要加练多少”。

学习范围是**你勾选的词库**，不是系统偷偷限制的“当前等级 + 低一级”。

### 4. 选词库 → 乱序候选 → 亲手挑词

1. 进入选词页，**可以多选词库**，例如高中 + 雅思一起选；
2. 系统每批乱序给 **20 个纯新词**，不管目标多少都是 20 个一批；
3. 你点选不认识的词；没选够就点“换一批”，**已选词会保留**，只换候选；
4. 直到选够目标数量，或先用手上这些；
5. 没点中的候选词，默认标记为“已会”，以后不再推送（页面有勾选框可以取消）；
6. 选完出现两个入口：**直接学习这 N 个词**，或 **生成文档打印**；
7. 学习时严格按你点的词来，**10 个一组**。

### 5. 每组三遍

**第一遍：详细学**
- 英文、音标、完整中文多义项；
- 有道 / 剑桥 / 必应跳转；
- 有道在线发音；
- 词形变化：复数、过去式、过去分词、现在分词、比较级等；
- 词族：词典里真实存在的动词→名词、动词→形容词等；
- 词典信息：词性、英文释义、柯林斯星级、牛津核心、COCA/BNC 词频。

**第二遍：看英文想中文**
- 只给英文，自己回想；
- 想不起来再点“显示中文”。

**第三遍：默写 / 选择混组**
- 每个词随机是“完全默写”或“4 选 1”；
- 默写只给中文意思 + 可选发音按钮，**不提示字母、不提示长度、不做字母填空**；
- 答错自动进错题本。

规则：

- 答错 → 自动进错题本，记忆等级降回 L1；
- 答对 → 等级上升；
- **连续答对 3 次 → 标为 L5 掌握**（中途答错会重新计数）；
- 到 L5 后不再进入新词池，之后你自己回去继续背；
- 测试中勾选“认识”的词直接 L5。

### 6. 查词

左侧导航新增独立的 **“查词”** 页面：

- 搜索单词、音标或中文释义；
- 按等级、状态筛选；
- 勾选后导出 PDF / Word / Excel；
- 不再和“词库与导出”混在一起。

### 7. 大复习 / 默写

“大复习”会按权重抽词：

- 错题本权重最高，错得越多越优先；
- L1–L4 半熟词偶尔抽查；
- L5 已掌握词极低概率出现；
- 支持“只练错题”；
- 支持 **默写模式**：全部听音/看中文写英文；
- 支持 **默写某一天** 的词；
- 支持 **默写上次打印包**。
- 错题本可以导出 **PDF / Word / Excel** 三种格式。

### 8. 日程表

导航栏“日程”会记录：

- 每天学了多少词、学了几次、正确率；
- **今天选了什么词**（手动选词开始学习/打印时记录）；
- **今天学了什么词**（实际答过的词）；
- **今天打印了什么词**（每次导出记录打印包和词表）；
- 最近 4 周日历，颜色越深学得越多；
- 点某一天，可以按“选词 / 学习 / 打印”三个模块分别复习或默写；
- 最近记录列表；
- “大复习默写”入口。

### 9. 时间不够：一周打印包

如果这周没时间天天开软件，去“词库与导出”：

**随机打印包**
1. 选词库（例如 L5 雅思）；
2. 选数量 100–200；
3. 选乱序 / 字母序；
4. 选中英对照 / 纯英 / 纯中；
5. 选“排除已掌握”；
6. 点“生成 PDF 打印包”（也可以 Word / Excel）。

**手动挑词打印**
1. 点“手动挑词打印”；
2. 选一个或多个词库；
3. 系统每批乱序给 **20 个候选词**；
4. 只点自己不认识的词；没选够就“换一批”，已选词保留；
5. 没点中的候选词会标记为“已会”，以后不再推；
6. 点“打印 PDF 这 N 个词”（也可以 Word / Excel）。

生成后会自动记入“上次打印包”。周末回来：

- 在“日程”或“大复习”里点“默写这包”；
- 软件会从这 100–200 个词里抽 30 个默写。

> 导出时会让你选一个**文件夹**，软件自动在里面建 `VocabBoost-导出` 子文件夹再写文件。这样可以绕开 Windows 对“桌面/盘符根目录直接建文件”的限制；桌面、D 盘都可以选。同名文件被 Word/Excel 占用时，会自动改名为 `-2`、`-3`。

这样就形成：

```text
周中：打印纸背
周末：软件默写复习
```

## 二、词库

来自 ECDICT，整理后共 **15,062 个考试相关单词**：

| 等级 | 名称 | 词数 | 说明 |
|---|---|---|---|
| L1 | 初中 | 1,612 | 中考核心 |
| L2 | 高中 | 2,455 | 高考主战场 |
| L3 | 四级 | 1,606 | CET-4 |
| L4 | 六级/考研 | 2,189 | CET-6 / 考研 |
| L5 | 雅思/托福 | 3,757 | IELTS / TOEFL |
| L6 | GRE | 3,443 | GRE |

每个词：

```json
{
  "w": "单词",
  "p": "/音标/",
  "z": "完整多义项中文释义",
  "l": 1,
  "tags": ["zk", "gk"]
}
```

> 只保留带考试标签的词，并用 COCA 词频做保守校准，避免把 “best” 这种基础词误标成雅思/GRE。

## 三、数据保存

数据在发行版目录（启动器旁边）：

```text
VocabBoost-Data\
  english-trainer-data.json
  english-trainer-data.json.bak
  vocabboost.log
```

换电脑时，把整个 `VocabBoost-2.2.0-win64` 文件夹（含启动器、`dist`、`VocabBoost-Data`）一起拷走。

### 想改软件里的“使用说明”文字？

直接编辑：

```text
C:\Users\Administrator\Desktop\English\VocabBoost-2.2.0-win64\VocabBoost-Data\使用说明.txt
```

这是纯文本，支持中文、空行和小彩蛋；保存后**重启软件**即可生效，不需要重新打包。

另外两份文字：

- `VocabBoost-2.2.0-win64\使用说明.txt`：给用户看的纯文本说明；
- `C:\Users\Administrator\Desktop\English\README.md`：项目说明；
- 源码里的 `config.json` 的 `helpText` 是默认内容，重新打包时会写进程序。

设置 → 本地数据：

- 打开数据文件夹；
- 导出 JSON 备份；
- 导入备份；
- 清空当前用户进度。

> 第一次启动时会在发行版目录创建 `VocabBoost-Data`。如果想换新用户，可以在设置里清空进度；清空前建议先导出备份。

## Windows、体积、手机、打包

### 为什么 exe 有 200 多 MB？

主要是 **Electron/Chromium 运行时**，不是词库：

- `VocabBoost.exe` 本体约 239MB；
- `words.json` 只有约 4.6MB（15,062 词 + 详细字段）；
- Electron 自带浏览器内核、GPU、PDF 打印等能力，所以体积大。

已经做的优化：构建时只保留 `zh-CN / zh-TW / en-US / en-GB` 四个语言包，删掉其余 50 多个 locale，减少约 25MB。如果要做成 10–20MB 的软件，需要换成 Tauri/WebView2 或纯原生 UI，属于重写，不是换打包参数。

### 手机能用吗？

当前是 Electron，**不能直接装到手机**。以后可以：

1. 做响应式网页版/PWA，手机浏览器直接用（最快）；
2. 用 Capacitor 把同一套网页包成 Android/iOS App；
3. 用 Flutter/React Native 重写界面（工作量大）。

按你的优先级，这个最后做。

### 发给别人怎么打包？

推荐 **“文件夹版 7Z/ZIP”**：

1. 直接用现成的 `VocabBoost-2.2.0-win64` 文件夹；
2. 关闭软件后，右键该文件夹 → 7-Zip → 添加到压缩包；
3. 对方解压后双击 `VocabBoost-Launcher.exe`。

不推荐只发单文件便携版：便携外壳依赖临时目录，在这台机器上会报错。  
如果你要更“安装软件”的体验，可以再做一个 NSIS 安装包，安装时创建带 `--no-sandbox` 参数的快捷方式；但 7Z 文件夹版最稳、最容易排错。

## 五、开发与重新打包

源码仓库不包含 `node_modules`、`dist`、`ecdict.db`、用户数据和发行版文件夹。

```powershell
# 1. 安装依赖
npm install

# 2. 开发运行
npm start

# 3. 重新生成词库（需要自己准备 ecdict.db，仓库不包含）
python build_words.py

# 4. 打包文件夹版
npm run build
```

产物：

```text
dist\win-unpacked\VocabBoost.exe
```

启动器源码在 `tools\launcher.cs`，编译命令示例：

```powershell
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe `
  /target:winexe /win32icon:assets\icon.ico `
  /out:VocabBoost-Launcher.exe tools\launcher.cs
```

发行版目录结构：

```text
VocabBoost-2.2.0-win64\
  VocabBoost-Launcher.exe
  启动 VocabBoost.cmd
  使用说明.txt
  LICENSE
  dist\
    win-unpacked\
```

## 九、上传到 GitHub

源码仓库只放源码，不放 `node_modules`、`dist`、`ecdict.db`、用户数据和发行版文件夹（已在 `.gitignore` 中忽略）。

```powershell
# 在 GitHub 新建一个空仓库后：
git remote add origin https://github.com/<你的用户名>/VocabBoost.git
git push -u origin main
```

发行版：

1. 把 `VocabBoost-2.2.0-win64` 文件夹右键压缩成 7Z（或 ZIP）；
2. 在 GitHub 仓库页面点 **Releases → Draft a new release**；
3. Tag 填 `v2.2.0`，把 7Z 拖进附件；
4. 发布即可。

> GitHub 仓库单文件限制 100MB；Release 附件最大 2GB。发行版 7Z 放 Release，不要提交进仓库。
