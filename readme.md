# 📚 English Trainer

无需安装、双击即用的英语单词学习工具。

✨ 功能

- 🔤 **10 个内置词库**：初中/高中/四六级/考研/雅思/托福/GRE/牛津3000  共45000+词汇
- 🎯 **智能筛选**：设定每日目标，只学不认识的词
- 🔄 **三遍学习法**：跟读记忆 → 看英文想中文 → 看中文默写英文
- 📖 **深度学习**：一键跳转有道/剑桥/柯林斯/牛津查词组搭配
- 🎲 **随机大复习**：从已掌握词汇中随机抽取巩固
- 📝 **错题本**：自动收集默写错误的词
- 📊 **学习报告**：已掌握/错题本/今日已学，点击查看详情
- 🖨️ **导出打印**：A4 词汇表（仅英文/仅中文/中英对照）
- 📱 **全平台**：Windows / Mac / Android / iPhone / iPad

## 🚀 使用方法

1. 下载 `英语学习工具.html`
2. 双击打开
3. 选词库 → 设目标 → 筛选词汇 → 开始学习

> 分享给朋友只需要发这一个 HTML 文件。
